# Blinkit Sales Data Analysis

## Project Overview
This project performs exploratory data analysis (EDA) on Blinkit sales data using Python to uncover insights related to product performance, outlet characteristics, and location-based sales trends.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights
- Supermarket Type1 generates the highest total sales.
- Tier 3 locations contribute the largest share of revenue.
- Medium-sized outlets outperform small and large outlets.
- Sales are concentrated among a few high-performing product categories.

## Business Impact
The analysis supports data-driven decisions for outlet expansion, inventory optimization, and location-based strategy.
