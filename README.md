# Blinkit Sales Data Analysis


## Project Overview
This project performs an end-to-end exploratory data analysis (EDA) on Blinkit sales data using Python in Jupyter Notebook. The goal is to understand sales performance, outlet behavior, product trends, and business KPIs to support data-driven decision making.


## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook


## Key Insights
- Supermarket Type1 contributes the highest revenue.
- Fruits and Vegetables category has maximum sales.
- Tier 3 outlets show strong sales potential.
- Outlet age positively impacts sales performance.
- Ratings are mostly between 3.5 – 4.5 showing customer satisfaction stability.


## Business Recommendations
- Expand Supermarket Type1 in Tier 3 locations.
- Increase inventory for high-performing categories.
- Improve visibility for low-selling products.
- Focus on newer outlets with marketing campaigns.
